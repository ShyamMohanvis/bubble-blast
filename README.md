# 🫧 Bubble Blast

A polished 2D Bubble Shooter browser game built with **Phaser 4 + TypeScript + Vite**.

## 🎮 Play Now

### **[▶ Play Bubble Blast](https://shyammohanvis.github.io/bubble-blast/)**

## 🎯 How to Play

- **Aim** by moving your mouse/finger
- **Shoot** by clicking/tapping above the shooter
- **Match 3+** same-colored bubbles to pop them
- **Clear all bubbles** to advance to the next level
- **Swap** the current bubble with the next one using the swap button

## ✨ Features

- 🎨 Premium purple-themed UI with cyan neon accents
- 🏆 10 levels with increasing difficulty
- 🔄 Bubble swap mechanic
- 💥 Pop and drop effects with particle feedback
- 🔊 Sound effects (toggle on/off)
- ⏸️ Pause menu with restart option
- 💾 Auto-save progress (localStorage)
- 📱 Responsive — works on desktop & mobile

## 🛠️ Tech Stack

- **Phaser 4** — Game framework
- **TypeScript** — Type-safe code
- **Vite** — Fast build tooling
- **GitHub Pages** — Hosting via GitHub Actions

## 🚀 Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
